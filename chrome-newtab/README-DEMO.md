# Memento 4.0 Preview · Chrome 新建页 Demo

这是 Memento 4.0 的独立前端预览。它使用固定的合成数据，展示时间河、认知地景和“她理解的我”，不要求数据目录授权。

## 快速加载

1. Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择当前文件夹。
4. 新开标签页。

本目录可被安全地作为本地演示扩展加载。它不读取 `~/AISecretary`，不请求网络，也不调用模型。完整安装步骤和 SHA-256 校验见仓库的 [`docs/MEMENTO_DEMO_INSTALL.md`](../docs/MEMENTO_DEMO_INSTALL.md)。
