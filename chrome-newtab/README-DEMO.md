# Memento 4.0 Preview · Chrome 新建页 Demo

这是 Memento 4.0 的独立前端预览，界面更新于 2026-09-06。它使用固定的合成数据，展示时间河、认知地景、“她理解的我”和默认按标签浏览的记录轨迹。

在线体验支持地图缩放、主题与记忆详情、按标签和时间查找记录。公开预览锁定示例数据，不提供目录授权、本机连接或真实数据写入。快捷键采集、Apple OCR、语音和 AI 整理需要本地安装版；在线页面的 21:00 自动整理控件会明确标为不可用。

## 快速加载

1. Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择当前文件夹。
4. 新开标签页。

本目录可作为本地演示扩展加载。公开预览不读取个人数据、不连接后端，也不调用模型。共享 manifest 保留本地安装所用的 loopback 主机权限；公开预览的运行时隔离会阻止这条连接。完整安装步骤和已发布安装包的 SHA-256 校验见 [Memento Demo 安装说明](https://github.com/Luke20001024/Memento/blob/main/docs/MEMENTO_DEMO_INSTALL.md)。本次网页更新不会自动更新之前下载的安装包。
