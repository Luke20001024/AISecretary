# Memento 4.0 Preview · Chrome 新建页 Demo

这是独立、固定数据的前端产品预览。它展示时间河、认知地景与“她理解的我”，不会读取真实文件夹，不连接模型，也不会创建后台任务。

## 快速加载

1. Chrome 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择当前文件夹。
4. 新开标签页。

详细步骤与 SHA-256 校验见仓库的 [Chrome Demo 安装说明](https://github.com/Luke20001024/Memento/blob/main/docs/MEMENTO_DEMO_INSTALL.md)。在线说明书与预览位于 [GitHub Pages](https://luke20001024.github.io/Memento/)。
