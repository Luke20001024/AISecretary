# Memento 认知秘书桌面 · 聚焦版 PRD

> 状态：新版功能设计稿
> 日期：2026-08-17
> 说明：本文先复盘线上能力，再重新定义新版桌面。现有功能只作为需求与数据基础；旧入口可以删除、合并或降级。逐条整理、可用记忆与认知地景仍属于目标能力。

## 0. 统一产品叙事口径

本文遵循 [Memento 产品叙事统一口径](MEMENTO_PRODUCT_NARRATIVE.md)。新版桌面承接三项价值：**接住正在发生的意图**、**长期理解你的形状**、**让每个 AI 都从同一个你开始**。

本 PRD 的首页设计集中呈现前两项：记录如何被接住、整理并形成地景和长期理解。第三项通过 **可调用的个人记忆** 接入输出与外部工作流，不再使用“支持多端接入”或“让理解被授权调用”作为产品价值标题。

## 1. 新版要实现什么

Memento 要成为一个持续接住记录、逐条整理、按天归并，并用原文证据更新长期理解的个人认知秘书。

新版主页只有两件核心内容：

```text
上半部：她目前如何理解我
下半部：我今天留下的内容被整理成了什么
```

这次改版不以兼容旧页面布局为目标。线上能力只用于确认已有资产和用户价值；新版入口、层级与交互按照“理解如何形成、记录如何被消化”重新设计。

用户打开新标签页时，应当立即获得三种感受：

1. 我长期关心和反复实践的方向正在形成清楚结构。
2. 今天的每条记录已经被接住，并得到可核对的整理结果。
3. 任何理解都能回到原文，也能被我修改、删除或停止使用。

## 2. 线上版本完整复盘

### 2.1 当前能力地图

| 能力层 | 已有能力 | 当前入口 |
|---|---|---|
| 主动记录 | 文字、备注、标签、截图、OCR、语音、原始附件 | macOS Service 与当前窗口 |
| 原始事实 | 时间、来源 App、日期、Markdown、原始资产 | 本地数据目录与主页记录流 |
| 时间回看 | 今日记录、本周统计、90 天痕迹、日期切换 | 新标签页主页 |
| 记录筛选 | 全部、灵感、下次再读、TODO | 主页记录区 |
| 外部输出 | 时间范围、Prompt 风格、复制给 AI、Memento 卡片 | 主页首屏 |
| 每日回顾 | 每日第一帧、Daily Review、总结状态、补跑 | 每日总结抽屉 |
| 长期理解 | 新增、强化、修订、张力、依据、反例、适用范围 | 关于我抽屉 |
| 人工校准 | 编辑、删除、版本历史、失败时沿用旧版 | 关于我抽屉 |
| 自动整理 | 立即核对最近 14 天、每日 21:00 计划 | 关于我抽屉 |
| 成品归档 | HTML 导入、安全预览、删除 | 归档抽屉 |
| 本地信任 | 目录授权、缓存恢复、来源校验、原子写入、失败保护 | 后台状态与深层说明 |

### 2.2 当前页面组织

线上页面形成了四个相对独立的中心：

1. **主页中心**：今日记录与复制给 AI。
2. **关于我中心**：长期理解、整理控制和人工校准。
3. **每日总结中心**：按日照片、总结与状态。
4. **归档中心**：AI 生成 HTML 的导入与查看。

2026-08-17 的截图把结构错位呈现得很直观：主页因“今天无记录”留下大面积空白；与此同时，“关于我”抽屉已有 3 条长期理解并显示最近更新，“每日总结”抽屉已有 12 个记录日。长期价值已经存在，但默认主页无法承接。

### 2.3 当前版本的优势

- 原文、时间、来源和附件都有明确位置；
- 90 天痕迹与每日第一帧形成了独特的时间感；
- 长期理解已经可以查看依据、反例、编辑、删除和版本；
- 右侧抽屉适合认真阅读，又不会长期占据新标签页；
- 暖白底板、墨色文字、发丝线和克制留白符合 Memento 调性；
- 本地优先、渐进恢复和失败不覆盖旧结果已经建立信任基础。

### 2.4 当前版本的结构问题

- 主页第一注意力被“复制给 AI”占据，Memento 自身的整理结果没有成为主角；
- 今天无记录时，主页接近空白，已有长期理解无法持续产生价值；
- 原始记录直接跳到长期理解，中间的逐条拆解与可用记忆不可见；
- 关于我是一张完整的第二首页，和主页面争夺产品中心；
- Daily Review 与长期理解分别运行，用户看不到当天总结怎样进入长期理解；
- 三个右侧竖签承担一级导航，超宽桌面上发现成本高；
- 运行控制、产品内容和诊断信息混在同一抽屉中。

## 3. 从线上能力得到的新版决策

旧功能不按原位置搬运。新版按用户任务重新组合。

| 线上模块 | 用户真正需要的价值 | 新版决策 |
|---|---|---|
| 复制给 AI 与 Memento 卡片 | 把记录带到其他工具继续使用，并保留常用输出样式 | 从首页主按钮降为“输出与导出”工具；Memento 卡片成为输出预设 |
| 今日原始记录流 | 确认内容已经保存并能找回 | 改为 AI 整理结果流；原文进入详情 |
| 90 天痕迹 | 感知记录连续性与切换日期 | 升级为全页时间控制，联动地景和记录 |
| 关于我抽屉 | 看见并校准长期理解 | 取消独立首页；核心内容提升到主屏上半部 |
| 现在整理 | 主动检查近期理解 | 放入认知地景控制区，命名为“核对近期理解” |
| 21:00 计划 | 自动完成每日整理 | 主页仅显示状态；开关和详情进入整理设置 |
| 每日总结抽屉 | 回看某一天的现场与总结 | 合并为“每日历史”，当天结果直接进入记录区 |
| 每日第一帧 | 给日期留下人的现场 | 继续服务每日历史，不参与人物理解证据 |
| 归档抽屉 | 保存和打开成品 | 合并进工具与导出，不再占一级入口 |
| 旧标签筛选 | 快速过滤记录 | 逐步升级为内容类型、主题、用途、状态筛选 |
| 运行轨迹与用量 | 排障与成本查看 | 收入诊断区，不进入主页叙事 |
| 三个右侧竖签 | 打开附属功能 | 取消；改为一个统一上下文侧栏和一个工具入口 |

## 4. 新版产品层级

新版把“记录”和“理解”之间补成完整链路：

```text
原始记录
→ 逐条内容拆解
→ 可用记忆
→ 每日关系归并
→ 长期理解
→ 认知地景
→ 用户反馈与结果回流
```

### 4.1 原始记录

保存用户真正说过、写过和截取过的内容，包括时间、来源和附件。

### 4.2 逐条内容拆解

每条记录形成一份可检查的整理结果：

- 内容类型；
- 主题与对象；
- 用户与内容的关系；
- 当前认知状态；
- 后续用途；
- 与其他内容的候选关系。

### 4.3 可用记忆

将一条记录拆成一个或多个可以被检索、关联和引用的记忆点。一个记忆点必须能回到原文。

### 4.4 每日关系归并

每天统一处理重复、支持、反例、冲突、适用条件和多主题拆分。

### 4.5 长期理解

只有跨时间证据达到条件后，才形成、强化、修订或保留一条长期理解。

### 4.6 认知地景

地景只投影已经落库并通过校验的长期理解、可用记忆和关系。视觉层不自行推断。

## 5. 新版桌面信息架构

```text
全局工具栏

认知地景
├── 当前理解
├── 近期变化
├── 记忆点与关系
└── 核对近期理解

90 天时间轨道

今日整理状态

今天留下的记录
├── AI 整理结果
├── 关联主题与认知峰
└── 整理与校准状态

统一右侧栏
├── 山峰详情
├── 记录与原文
├── 今日归并
├── 每日历史
└── 设置、输出与诊断
```

### 5.1 完整产品导航

主页承担“每天打开就能获得价值”的聚焦体验；其余能力进入清楚的二级空间。

| 一级区域 | 主要内容 | 解决的问题 |
|---|---|---|
| 首页 | 认知地景、今天整理后的记录、今日归并状态 | 我现在被怎样理解；今天的内容去了哪里 |
| 记录 | 完整日期、来源、类型、主题、状态筛选；整理结果与原文切换 | 找回过去留下的具体内容 |
| 认知 | 全部认知峰、历史变化、仍在观察、版本回望 | 深入理解长期认知结构及其变化 |
| 资料库 | 每日总结、每日第一帧、HTML 归档、输出 | 回看日常现场并管理形成的成品 |
| 设置 | 整理计划、数据目录、模型、用量、隐私、兼容与诊断 | 控制系统怎样运行 |

导航使用安静的固定侧栏或顶栏入口。首页不重复展示二级页面的完整内容。

### 5.2 首页与二级空间的关系

- 首页认知地景只显示当前重点与最近变化；认知页提供全量地图和版本历史。
- 首页只显示当天整理结果；记录页负责完整历史和原文检索。
- 首页只显示今日归并状态；资料库负责历次 Daily Review、照片与归档。
- 右侧栏负责当前对象的上下文，不承担全站导航。

## 6. 主页分区设计

### 6.1 全局工具栏

只放全局能力：

- Memento；
- 当前日期或查看日期；
- 搜索与找回；
- 当前整理状态；
- 工具入口。

搜索支持查找原始记录、整理结果和长期理解。搜索结果始终区分三种内容层级。

主动记录继续以 macOS Service 为主要入口，保留文字、截图、OCR 和语音等现有采集方式。新标签页负责显示即时回执与整理状态，不要求用户为了记录先回到主页。页内“快速记录”可以在后续作为次要入口验证，首版不占据主视觉。

### 6.2 上半部：认知地景

认知地景是主页第一视觉，回答三个问题：

1. 现在形成了哪些长期认知取向？
2. 最近哪一项发生了变化？
3. 它们由哪些记录和反例逐步形成？

#### 地景对象

| 视觉对象 | 含义 |
|---|---|
| 山峰 | 一条已提交并通过校验的长期理解 |
| 等高线 | 跨时间积累的有效依据 |
| 实心点 | 已完成每日归并的可用记忆 |
| 空心点 | 今天已初步整理、等待归并的内容 |
| 实线 | 支持关系 |
| 虚线 | 反例或张力 |
| 方向线 | 理解修订的来路 |
| 淡蓝阴影 | 近期再次出现或本次发生变化 |

地景同时提供文字摘要：

> 当前 4 项理解 · 1 项近期变化 · 2 项仍在观察

#### 地景交互

- 点击山峰：打开该项理解的详情侧栏；
- 点击记录点：打开对应整理结果与原文；
- 点击关系线：显示关系类型、来源和形成时间；
- 选择下方记录：地景高亮它参与的一个或多个峰；
- 切换时间范围：只改变当前视图，不改写长期理解；
- 选择“列表视图”：用等价文字列表替代地景，便于精确阅读。

### 6.3 90 天时间轨道

沿用线上版的细条语言：

- 继续表达每天记录数量；
- 点击日期后，上方地景进入当时视角，下方切换到该日记录；
- 当前日期、选中日期和发生认知变化的日期有不同标记；
- 时间轨道不表达情绪、成长程度或人格强度。

### 6.4 今日整理状态

上下两层之间显示一行加工进度：

> 今天已保存 5 条 · 已整理 4 条 · 形成 7 个记忆点 · 2 条等待今晚归并

提供两个动作：

- **归并今天**：统一处理今天的重复、关系和多主题拆分；
- **查看整理详情**：查看等待、失败和需要校准的项目。

长期层的“核对近期理解”与当天的“归并今天”分开，避免一个按钮同时承担两个任务。

### 6.5 下半部：今天整理后的记录

下半部展示每天的 AI 整理结果，原文点击后查看。

每条记录包含：

- 时间与来源；
- 一句整理结果；
- 内容类型；
- 主题或对象；
- 后续用途；
- 当前整理状态；
- 关联的零个、一个或多个认知峰。

示例：

```text
10:50 · 语音
我的观察 · 产品设计
完备性可能推迟真实反馈
关联：产品判断 / 记录方式
已初步整理 · 等待今日归并
```

点击后按以下顺序展开：

1. AI 将它整理成了什么；
2. 它被拆成了哪些记忆点；
3. 它连接到哪些认知峰；
4. 原始记录、来源与附件；
5. 正确、改一下、仅保存原文。

## 7. 统一右侧栏

新版只保留一个上下文侧栏。它根据当前点击对象切换内容，只承载当前对象的摘要、证据与快捷操作。完整历史、全量地图和系统设置分别回到资料库、认知和设置页，侧栏不承担全站导航。

### 7.1 山峰详情

- 当前理解与适用范围；
- 最近一次变化；
- 最强支持和最强反例；
- 全部关联记忆点和原始记录；
- 版本历史；
- 编辑与删除。

### 7.2 记录详情

- 逐条拆解结果；
- 一个或多个记忆点；
- 关联峰与关系；
- 原始记录、来源和附件；
- 正确、改一下、仅保存原文。

### 7.3 今日归并

- 今日处理进度；
- 去重、拆分、关系与冲突；
- 等待、失败和需要校准的项目；
- 归并今天。

### 7.4 每日历史

- 当前日期的第一帧与总结摘要；
- 当天整理状态与恢复操作；
- “查看完整每日历史”入口。

### 7.5 工具与设置

- 复制给 AI、Memento 卡片与输出样式快捷入口；
- 最近一次归档与导入状态；
- 21:00 计划状态与下一次计划；
- “打开资料库”和“打开设置”入口。

## 8. 核心用户工作流

### 8.1 留下一条记录

```text
用户在当前窗口主动记录
→ 原文立即本地保存
→ 新标签页出现“原文已保存”
→ AI 返回轻量整理结果
→ 用户看到它被归到什么主题、可能连接哪些认知峰
→ 等待今日归并
```

即时整理可以提出候选关系，不能直接新增或修改山峰。

### 8.2 每日归并

```text
今天的逐条整理结果
→ 去重和多主题拆分
→ 形成可用记忆
→ 查回历史与现有理解
→ 建立支持、反例、修订或边界关系
→ 通过来源与版本校验
→ 更新认知地景
```

### 8.3 浏览一项理解

```text
点击山峰
→ 先读当前理解
→ 查看最近变化
→ 查看支持与反例
→ 定位相关记录
→ 按需打开原文
```

### 8.4 校准一条记录或理解

```text
正确 / 改一下 / 仅保存原文 / 删除理解
→ 保存独立用户反馈
→ 后续 Agent 以用户版本为基线
→ 整理结果和地景同步变化
```

### 8.5 找回过去内容

```text
输入问题或关键词
→ 先返回直接答案或相关理解
→ 展示原文引用、时间和变化
→ 标出仍然未知的部分
```

该能力进入逐条整理与可用记忆稳定后的下一阶段。

## 9. Agent 与 Workflow 分工

| 阶段 | Agent 做判断 | Workflow 控制执行 |
|---|---|---|
| 逐条整理 | 类型、主题、用途、状态、候选关系 | 保存原文、确保记录唯一、校验结果，避免重复创建 |
| 每日归并 | 去重、拆分、支持、反例和冲突 | 读取当天与历史材料，维护处理进度和关系 |
| 长期理解 | 新增、强化、修订、张力或停止 | 回查逐字原文、来源、版本和用户动作，通过校验后提交 |
| 地景呈现 | 不直接生成视觉状态 | 投影已校验的峰、点、线和版本 |

## 10. 信息对象

### 10.1 原始记录

用户原文、时间、来源、附件，以及用于确认原文未被改动的校验信息。

### 10.2 整理结果

一条记录的内容类型、主题、关系、状态、用途和处理状态。

### 10.3 可用记忆

从原始记录中拆出的最小可引用内容，可以同时服务多个长期理解。

### 10.4 长期理解

有适用范围、依据、反例、不确定性和版本的当前判断。

### 10.5 关系

支持、反例、修订、适用条件不同和来源关系。任何关系都要能回到原文。

### 10.6 用户反馈

正确、修改、仅保存原文、删除和现实结果。反馈与 AI 输出独立保存。

## 11. 页面状态

| 状态 | 页面表现 |
|---|---|
| 今天无记录 | 认知地景继续显示；下半部安静提示今天还没有记录 |
| 原文已保存 | 记录立即出现，明确显示原文安全保留 |
| 正在即时整理 | 仅当前记录显示轻量进行态 |
| 即时整理失败 | 原文保留，允许重试，不生成记忆点 |
| 等待每日归并 | 地景出现空心点，不提前生成山峰 |
| 今日无长期变化 | 显示“今日已归并，没有改变长期理解” |
| 证据不足 | 不生成山峰；整理结果仍可检索和查看 |
| 长期核对中 | 继续显示上一版地景 |
| 新结果校验失败 | 保留上一版只读地景，并显示克制警告 |
| 部分记录读取失败 | 展示其余可信内容，说明缺失范围 |
| 目录权限失效 | 进入恢复访问状态，不把缺数据呈现为空记忆 |
| 21:00 计划已保存 | 只说明计划有效，不等同于当天执行成功 |

## 13. 产品边界

- 地景表达用户主动记录形成的局部理解，不代表完整人格。
- 每条记录都会得到整理机会，但不会自动升级为长期理解。
- 一条记录可以形成多个记忆点，也可以关联多个峰。
- 原始记录、整理结果和长期理解是三个独立层级。
- AI 摘要不能成为长期理解的独立证据，最终依据回到原文。
- 山峰高度只表达经校验证据的累积。
- 峰间位置用于稳定排版；远近本身不表示关系、相似性、语义矛盾或重要程度，视觉距离不作为事实。
- 只有正式连线表示已校验并保存的关系；稳定 hash 只为新峰提供初始位置种子。
- Projector 对没有直接正式边、也没有通过同一条 active reusable memory 形成两跳正式关系的峰执行确定性避碰；上一版仍满足避碰边界的安全坐标优先保留。
- 存在直接正式边，或通过同一条 active reusable memory 形成两跳正式关系时，相关峰可以局部接近；允许接近不使视觉距离成为事实。
- 正式关系撤回后，如果原坐标使无关系峰产生点击热区或 KDE 布局碰撞，Projector 确定性重排碰撞点，并保留其他安全坐标。
- 用户删除理解后，原始记录继续存在。
- 每日第一帧和装饰图像不参与人物理解证据。
- 没有新证据时，页面不制造变化。

## 14. 版本范围

### V1：逐条整理桌面

- 每条原始记录拥有唯一且可追溯的身份；
- 每条记录的即时整理状态和结果；
- 正确、改一下、仅保存原文；
- 整理结果与原文互相定位；
- 新主页上下分区建立；
- 只读基础地景：显示已存在的长期理解、近期变化与文字摘要。

### V2：每日归并与关系

- 一条记录拆出多个可用记忆；
- 记录、记忆点、长期理解形成多对多关系；
- 手动“归并今天”与 21:00 自动归并；
- 今日归并结果和异常恢复。

### V3：动态认知地景

- 地景随新理解、强化、修订和张力动态变化；
- 记忆点、支持、反例与修订关系可交互；
- 地景、记录和统一侧栏联动；
- 历史版本、时间视角，以及峰的合并、拆分和休眠表达。

### V4：找回与反馈

- 问过去的自己；
- 直接答案、原文引用、时间变化和未知项；
- 现实结果回流；
- 将找回结果带回创作、判断和复盘场景。

暂不进入前三个版本：自由拖拽地图、人格评分、复杂 3D 地形、持续动画、开放式多轮聊天。

## 15. 验收标准

1. 今天无记录时，已有认知地景仍然提供价值。
2. 新记录保存后，用户立即看到原文保存与整理状态。
3. 每条整理结果都能回到对应原文。
4. 一条记录可以关联零个、一个或多个认知峰。
5. 新峰只在长期理解完成校验和提交后出现。
6. 每次峰的变化都能解释新增依据、反例或范围。
7. 点击峰、点和下方记录能在同一侧栏互相定位。
8. 用户修改或删除后，后续整理尊重用户版本。
9. 失败不丢原文，也不覆盖上一版理解。
10. 复制、每日历史、归档和运行设置仍可从工具区到达，但不争夺主页注意力。
11. 主页第一屏不显示 Token、哈希、模型调用次数和运行轨迹。
12. 页面保持线上版的浅色、时间感、发丝线和右侧深阅读方式。
13. 页面明确说明峰间远近没有关系或重要程度语义，只有正式连线表示已校验关系，山峰高度只表示证据积累。
14. 无正式关联的峰不会因 hash 种子形成位置冲突；关系撤回后只确定性重排冲突点，其他安全坐标保持稳定。

## 16. 核心指标

- 新记录即时整理完成率；
- 用户选择正确、改一下、仅保存原文的比例；
- 每日记录进入可用记忆的比例；
- 记录与长期理解形成有效关系的比例；
- 认知峰被修改、删除和误生成的比例；
- 用户从地景返回原文的次数；
- 每周帮助找回信息、进入决定或修订判断的历史复用数。

## 17. 最终页面重心

```text
她目前如何理解我
→ 这些理解最近怎样变化
→ 我今天的内容被整理成了什么
→ 它们怎样连接到长期理解
→ 需要时查看原文、校准、回顾与导出
```

这份新版功能设计以“理解在上、记录在下”为主页骨架。线上功能提供数据、信任和交互基础；新版重新组织它们，让用户第一次打开页面就能看见 Memento 正在如何理解自己，也能立即核对每条记录的去向。
