# Memento 认知秘书桌面 Demo

这是一个完全本地、使用演示数据的桌面新标签页方案。它将已有的“认知地景”和“逐条整理回执”收进同一套页面结构，不修改原有两个 Demo。

## 打开

直接打开 `index.html`。

认知地景的等高线、节点和形成链沿用同一仓库中 `memento-cognitive-landscape` 的本地渲染引擎；页面不发起网络请求。

可选场景：

- `index.html`：完整状态
- `index.html?state=partial`：部分记录读取失败
- `index.html?state=empty`：新用户空状态

## 主页结构

1. **认知地景**：呈现跨时间形成的理解、记忆点和可追溯关系。
2. **今日整理队列**：连接即时逐条整理与每日长期归并，同时保留手动归并入口和 21:00 计划。
3. **今天留下的记录**：默认展示 AI 整理结果、记忆拆解、认知去向和处理状态。
4. **统一右侧抽屉**：承载长期理解的形成链、记忆和关系详情、单条整理回执、原文、每日历史、资料库、输出和设置。

## 关键交互

- 将鼠标移入地景：等高线会对当前区域做轻量响应。
- 点击山峰：抽屉展示“原始记录 → AI 整理 → 关系 → 当前理解”，下方同时强调对应记录。
- 点击当日记录：抽屉展示这条内容被整理成什么，上方同时强调它关联的峰与记忆点。
- 点击“归并今天”：只归并可直接写入的内容；需校准、失败和仅原文内容继续保留。
- 顶部次级入口：保留原有的每日历史、资料库、归档导入、输出和设置。

## 视觉约束

- 冷白底色、墨色文字、发丝分隔线。
- 雾蓝只用于地形阴影、记忆点、关系线和当前状态。
- 不使用大面积蓝色、卡片墙、粗重点击外框或装饰性地形。
- 所有详细证据和编辑操作统一进入停靠式抽屉，主页保持宁静。

## 离线边界

页面不请求网络，不读取真实用户数据，不会写入正式 Memento 存储。页面内修改在刷新后恢复。
