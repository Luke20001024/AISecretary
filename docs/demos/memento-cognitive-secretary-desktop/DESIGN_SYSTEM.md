# Memento「认知秘书桌面」三版设计系统

> 视觉基线来自 `docs/poster-intent` 的三套完整方向，每套 5 张。参考图影响页面的构图、材质、留白和色彩节奏，不承担人物证据，也不要求网页复制海报构图。

## 1. 产品命题

[猜测] 新标签页的第一任务是让用户迅速知道三件事：

1. Memento 当前保留了怎样的理解；
2. 这份理解从哪些原始事实与反例形成；
3. 用户今天又留下了什么。

[猜测] 主页承担日常回望，抽屉承担完整查证与操作。复制给 AI、归档、运行用量等工具继续保留，但不与“关于我”和“今天”争夺首屏。

## 2. 三版共同体验合同

三版使用同一份演示数据、相同功能、相同状态语义，只改变呈现调性与信息节奏。

### 主页

- 一条当前理解：分组、表述、适用范围、更新时间、版本、依据数、反例数；
- 3 条理解切换；
- 一条最小状态：无变化、整理中、已更新、失败或空；
- “查看依据”“改一下”“删除”“现在整理”；
- 每日 21:00 计划的本地模拟开关；
- 90 天记录痕迹与今天 5 条记录；
- 二级入口：全部理解、每日总结、归档与导出、关于本方案。

### 抽屉与浮层

- 全部理解：切换当前阅读对象；
- 依据与反例：日期、来源、关系和逐字原文；
- 编辑：只修改当前页内存中的演示文案；
- 删除：两步确认，只在当前页面隐藏理解，原始记录仍保留；
- 每日总结：说明本地 Demo 的状态，不假装生成真实总结；
- 归档与导出：模拟入口，不访问剪贴板、不写文件；
- 关于本方案：说明该方向的产品目标、调性、适用优势与风险。

### 状态

| 状态 | 用户可见语义 |
|---|---|
| `no_change` | 本次核对没有更新，保留上一版理解 |
| `processing` | 正在核对，完成前继续保留当前理解 |
| `updated` | 演示状态：一个新版本已写入 |
| `error` | 本次未完成，旧版理解继续保留 |
| `empty` | 证据不足，没有生成理解，原始记录仍在 |

## 3. 共享设计基础

| 角色 | 规则 |
|---|---|
| 画布 | 浏览器新标签页，桌面优先，最大内容宽 1180 至 1240px |
| 纸面 | 暖纸或浅灰纤维纸，不使用纯白 SaaS 画布 |
| 墨色 | `#1A1A1A` 至 `#2A2A28` |
| 次级文字 | `#77736C` 左右，正文对比度优先 |
| 分隔 | 0.5px 至 1px 发丝线，避免卡片墙 |
| 正文 | 系统中文无衬线；引用和理解正文可少量使用宋体 |
| 日期与来源 | `SFMono-Regular`, `Menlo`, `Monaco`, monospace |
| 当前理解 | 桌面 28 至 34px，移动端 24 至 28px |
| 主操作 | 每页只有一个视觉主操作；最小点击区 44px |
| 动效 | 只表达选择、展开、完成和时间切换；支持 `prefers-reduced-motion` |
| 图像 | 只作“视觉意向，非用户证据”，与依据区明确分隔 |

## 4. Direction 01 · Quiet Evidence / 安静证据

### 审美方向

- 暖象牙纸、撕边、透明校样纸、档案签、细线和小幅朱红修订；
- 65% 至 85% 留白，视觉焦点小且偏离中心；
- 一条理解像一张仍连着来源的校样，证据像页边脚注；
- 唯一高饱和色：朱红 `#D64022`。

### 页面签名

[猜测] 当前理解是一张“可校对的事实页”。主页只给最必要的来路，完整依据进入侧边抽屉。今日记录保持线性原文，不被 AI 文案覆盖。

### 用户体验目标

[猜测] 让用户首先感到可信、安静和可控。它最接近 Memento 现有品牌语言，适合作为生产骨架候选。

### 风险

[猜测] 视觉记忆点较克制，若信息密度处理不当会接近文档阅读页。

## 5. Direction 02 · Living Mirror / 生长镜面

### 审美方向

- 浅灰白纤维纸、粗颗粒黑墨、错位方块、圆孔、框线和方向性长条；
- 几何形只映射真实关系：黑色为当前结构，纸白负形为未知或边界，红色为变化或修订；
- 单一主事件，保留大面积空白，不制造人格图腾或装饰性脑图；
- 唯一高饱和色：番茄红 `#E12A1B`。

### 页面签名

[猜测] 当前理解被呈现为一个可被证据与反例重新排列的结构面。证据、反例和修订使用清晰的几何语法，但正文与逐字引用仍是判断依据。

### 用户体验目标

[猜测] 让用户看见“理解是一种持续校准的结构”，适合强调 Agent 与 Workflow 如何协作。

### 风险

[猜测] 抽象几何可能显得过于系统化，因此每个图形旁必须有可读标签，且几何不代替文本结论。

## 6. Direction 03 · Time Echo / 时间回声

### 审美方向

- 暖奶油纸、褪色相纸、透明描摹层、修补胶带和群青连接线；
- 图像使用无人、不可识别的生活静物，不暗示真实用户经历；
- 时间关系由日期、版本和蓝线表达；
- 唯一高饱和色：群青 `#2456D8`。

### 页面签名

[猜测] 当前理解像今天桌面上的一张小卡，旧记录从另一个时间被蓝线带回。主页强调连续性，抽屉展开完整证据与版本。

### 用户体验目标

[猜测] 让用户感到过去确实能够在今天被找回，最适合表达长期陪伴和“幸好它记住了”。

### 风险

[猜测] 情绪意象可能抢过实际信息，因此品牌图必须小于真实内容区，并持续标注“非用户证据”。

## 8. 响应式与质量门

- `1440 × 900`：当前理解、90 天痕迹和至少一条今天记录同屏；
- `1280 × 720`：理解正文不超过三行，主操作无需滚动；
- `768 × 1024`：多栏转单栏，理解先于意象和今日记录；
- `390 × 844`：无横向溢出，抽屉占满可用宽度，所有控件至少 44px；
- 键盘可打开与关闭所有抽屉或对话，关闭后焦点返回触发点；
- `prefers-reduced-motion` 下无持续位移；
- 页面不得调用网络、真实 API、剪贴板、本地存储或真实 Memento 数据；
- 三版截图使用相同视口、相同演示状态和相同内容，避免用不同数据制造优劣。
