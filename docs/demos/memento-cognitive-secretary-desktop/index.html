完全离线 · 演示数据 · 三版共用同一产品内容

设计命题

让理解来到主页，同时不挤走今天。

三版都先展示一条有来源、可修订的当前理解，并保留 90 天记录痕迹与今天的原始记录。复制、归档和运行审计退到工具层。

01 / QUIET EVIDENCE

安静证据

设计假设：把一条理解当作仍连着来源的校样页，用档案签、脚注和朱红修订建立可信感。最接近 Memento 当前品牌。

体验目标
安静、可信、可校对
主色
朱红 #D64022
风险
待验证：记忆点可能较克制
打开 Quiet Evidence
02 / LIVING MIRROR

生长镜面

设计假设：用黑色结构、纸白边界和红色变化表达理解如何被证据与反例重新排列，强调认知系统与校准过程。

体验目标
理性、先锋、可演化
主色
番茄红 #E12A1B
风险
待验证：抽象感可能偏强
打开 Living Mirror
03 / TIME ECHO

时间回声

设计假设：用旧相纸、描摹层和蓝色时间线把过去的事实重新带回今天，强调长期陪伴与 Context 的真实复用。

体验目标
温柔、连续、有人味
主色
群青 #2456D8
风险
待验证：意象可能抢内容
打开 Time Echo

三版共同回答同一个问题

  1. 01 Memento 当前怎样理解我？
  2. 02 这份理解来自哪些事实和反例？
  3. 03 我今天留下了什么？
  4. 04 我什么时候需要整理或校准？
