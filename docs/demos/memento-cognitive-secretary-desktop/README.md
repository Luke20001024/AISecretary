# Memento 认知秘书桌面 · 三版离线 Demo

本目录包含 3 个使用相同演示数据与相同功能的完整本地体验原型：

1. `01-quiet-evidence.html`：Quiet Evidence / 安静证据；
2. `02-living-mirror.html`：Living Mirror / 生长镜面；
3. `03-time-echo.html`：Time Echo / 时间回声。

从 `index.html` 进入对比页。三版都包含主页、全部理解、依据与反例、编辑、删除、整理控制、每日总结、当天完整记录、归档与导出、状态演示及方案说明。

页面完全离线，不调用网络、模型、剪贴板、本地存储或真实 Memento 数据。所有操作只改变当前页面内存状态，刷新后复原。

## 阅读顺序

- `PRODUCT_REVIEW.md`：当前产品功能、真实入口、AI Native 判断和本轮边界；
- `DESIGN_SYSTEM.md`：三版共享体验合同与三套视觉语言；
- `docs/poster-intent/README.md`：15 张原始视觉意向的长期罗盘；
- `prompts/`：三张新增配图的最终生成 Prompt；
- `screenshots/`：完成视觉验收后的桌面与移动端截图。

新增配图只作为品牌意向，不代表用户真实记忆或人物证据。
