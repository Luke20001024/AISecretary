# Memento / 今天留下的记录

这是一个完全离线、只使用演示数据的桌面端 HTML Demo，用于验证 Memento 主页下半部的产品流程。

## 打开

直接在浏览器中打开 `index.html`。页面不访问网络，不读写剪贴板，不使用本地存储。

## 产品状态

- 默认：`index.html`
- 空态：`index.html?state=empty`
- 部分失败：`index.html?state=partial`

## 可交互能力

- 筛选全部、待归并、需校准记录。
- 点击任一记录打开右侧整理详情。
- 查看原文、可用记忆和认知去向。
- 选择“整理正确”、“改一下”、“仅保存原文”或“重试整理”。
- 手动执行“归并今天”，待归并记录会在当前页面内更新状态。
- 每日历史、资料库、输出与导出、全部记录作为次级入口收入同一右侧栏。
- 资料库继续承接最近归档与导入、跨日资料以及 21:00 整理计划设置。

## 边界

该 Demo 不重复认知地景，只表达“原始记录 → 即时整理回执 → 候选记忆 → 每日归并 → 可用记忆”的主页下半部。

## 与完整主页的衔接

完整主页采用一条连续链路：

1. 上半部认知地景展示已经校验并提交的长期理解、可用记忆和正式关系。
2. 中间整理回执带说明今天保存、拆解、归并和待处理的数量。
3. 下半部逐条展示即时整理结果；候选记忆与候选认知去向不会提前改变地景。
4. 每日归并完成后，候选记忆成为可用记忆，正式关系才进入上半部地景。
5. 点击上方认知峰或下方记录，都使用同一个右侧栏回到记忆、关系和原文。

即时整理负责让用户马上知道“这一条被变成了什么”；每日归并负责跨记录去重、拆分和确认关系；长期理解核对负责决定是否形成、强化、修订或保留张力。三个阶段不共用一个模糊按钮。
