# Memento 认知地景离线 Demo

这是一个聚焦认知地图本身的桌面端离线 Demo，不包含完整主页与今天的记录列表。

## 这个 Demo 验证什么

- 用户能否在第一眼看懂当前形成了哪些长期理解；
- 峰、记忆点、关系线和版本变化是否具有清晰、可追溯的产品语义；
- 用户能否从地图进入长期理解、整理后记忆和关系详情；
- 时间回看能否解释山峰如何出现、强化、修订和形成张力；
- 空态、核对中、无变化、新峰、修订、张力和失败状态是否保持可信。

## 视觉语义

- 山峰代表已校验并提交的长期理解；
- 等高线由当前已提交的认知峰、已归并记忆点和跨峰桥接关系共同生成，表达跨时间有效依据的累积；
- 实心点代表完成每日归并的可用记忆；
- 空心点代表等待每日归并的内容；
- 实线代表支持，虚线代表反例或张力；
- 淡雾蓝只用于近期变化、选择状态、关系线和山体阴影。

峰间距离不表达人格相似度或重要程度。只有已经保存的关系才会被画出来。

当时间快照、记忆点或长期理解改变时，地形会使用同一组稳定位置重新计算。尚未归并的空心点和“仍在观察”区域不会生成新峰。

本轮地形渲染参考了 [obsidian-knowledge-map](https://github.com/fengyukongzhou/obsidian-knowledge-map) 中“二维节点 → 连续密度场 → 多层等高线”的生成思路，同时保留 Memento 的稳定峰位、已保存关系、版本与原文回溯。长期认知峰不会由自动聚类直接生成。

## 本地打开

直接打开 `index.html` 即可。页面不访问网络，不调用 API，不读写本地存储，所有操作只在当前页面模拟。
