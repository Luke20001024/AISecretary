## 统一产品叙事口径

Memento 的终态由三项连续价值构成：

1. **接住正在发生的意图**：多种入口把原文、时间、来源与原始资产留在本地；
2. **长期理解你的形状**：逐条记忆跨时间形成主题、依据和少量可修订的当前理解；
3. **让每个 AI，都从同一个你开始**：通过可调用的个人记忆，把与任务相关的理解带回写作、研究、编程与其他 AI。

第三项的用户价值是“让每个 AI 都从同一个你开始”，产品能力名称是“可调用的个人记忆”。Memory、MCP、本地工具、调用范围与读取审计属于实现方式和信任边界。

## 1. 产品最终要成为怎样的东西

Memento 是一套本地优先的个人认知记录系统。它持续接住用户主动留下的内容，在保留原文的前提下，逐渐识别跨时间反复出现的倾向，并把这些倾向呈现为可探索、可追溯、可修订的认知地景。

它最终回答三个问题：

1. 我最近持续在意和实践什么？
2. 这些理解分别来自哪些记录、边界和反例？
3. 多个主题长期交汇后，我正在走向哪里，我重视什么？

产品不替用户做每日评价，不生成侵入性的“今天的你怎样”结论，也不把视觉隐喻当成人格事实。

## 2. 产品的三层认知结构

### 第一层：主题地图

主页首先展示跨一段时间聚合形成的主题，例如“产品决策”“证据优先”“协作边界”。

- 主峰代表聚合主题；
- 次峰代表主题内部可复用的记忆与局部倾向；
- 山脉与等高线表达证据在时间中的积累；
- 连线只用于表达已经确认的关系；
- 地图位置服务于阅读和探索，不代表人格强度、真实性或重要程度。

当前 Preview 的地图是固定数据的静态制图呈现。全屏、平移、缩放、真实数据接线与关系聚焦属于后续实施范围。

当前视觉采用静态制图语言：高密度等高线、坐标网格、山峰三角标记、指北针和比例尺共同建立认知地景的阅读语境。鼠标光照、AO 阴影和持续动效已退出本轮方案。

### 第二层：形成依据

点击一个主题后，侧栏展示它如何形成：

- 当前倾向的简短表述；
- 适用范围与边界；
- 跨日期的代表记录；
- 与该倾向不完全一致的边界记录；
- 相关可用记忆与正式关系；
- 可返回的原始记录。

这一层承担核对。地图保持克制，解释和证据集中进入抽屉。

### 第三层：她理解的我

多个主题经过较长时间的共同积累后，收束为少量更深的理解：

- 我通常怎样做判断；
- 我在走向什么；
- 哪些价值和工作方式持续影响选择；
- 这些理解成立的范围和仍需保留的不确定性。

第三层只保留少量有来源的句子。它会随着新证据修订，不承担固定人格判定。

## 3. 记录流在产品中的位置

记录仍是全部理解的起点。最终产品保留文字、备注、标签、截图、OCR 和语音等基础记录入口，并保存时间、来源与原文。Preview 中展示的是固定合成记录。

主页先呈现当天记录形成的时间河，再进入地景与深层理解。用户可以：

- 确认记录已经保存；
- 查看记录是否形成主题线索；
- 看到记录进入了哪个主题；
- 从主题回到记录，也能从记录回到主题；
- 按日期进入“记录轨迹”，回看最近一段时间的内容去向。

正式数据接线后，新增记录会先保存，再进入后续的主题更新链路；当前 Preview 不接收真实记录，也不重新计算主题地图。

## 4. 已经收束掉的能力

以下能力不再进入产品主链：

- 每日照片与天气快照；
- 对一天进行独立评价的 Daily Review；
- 每天额外生成一段概括性总结；
- 与长期理解重复的“关于我”旧首页；
- 常驻主页的运行诊断、用量、技术状态和大段说明文字；
- 把归档、输出、模型控制放在认知主页一级导航。

已有历史文件遵循保留原则。能力退出不等于删除用户过去的数据。

## 5. 最终自动化链路

目标链路保持简洁：

```text
主动记录
→ 单条记录形成可检查的主题线索
→ 一天结束后处理重复、关系、边界与反例
→ 跨时间积累形成或修订主题
→ 多个主题收束为少量深层理解
→ 用户查看来源并进行校准
→ 按任务把相关个人记忆带回真实工作
→ 工作中的新证据继续进入形成链
```

自动化需要遵守这些边界：

- 原文先保存，派生结果后生成；
- 每项理解都能回到原文；
- 证据不足时允许不形成主题；
- 失败时保留上一份有效结果；
- UI 不直接调用模型；
- 模型密钥与调用只存在于本地 Worker；
- 用户编辑、删除和停止使用的决定优先于自动推演。

## 6. 主页最终形态

### 顶部

只保留品牌与三个事实数字：主题数量、近期变化、记录数量。

### 今天的时间河

当天记录紧接顶部出现，构成进入认知地景前的证据入口。时间被嵌入一条连续横轴；每条记录保留来源、原文摘要、主题去向和当前状态。用户可以横向连续浏览、用键盘沿时间移动，也可以逐条回到本地原文。

### 认知地景

地形图是主要视觉和主要交互面。主题名常驻；后续会随缩放逐级展开，主页与全屏共享同一探索语义。

关系交互安排在第二阶段：默认只呈现地形、记忆点和已确认的主题间关系；悬停主题后再出现主题到依据的关系，点击后固定聚焦并显示更多细节，再次点击退出。当前静态 MVP 只验收地图图像效果，不包含这组悬停与固定交互。

### 她理解的我

“她理解的我”常驻认知地景右侧，与地图共同构成首页主舞台。页面先完整呈现一条当前最重要的深层理解，再列出其余理解；每条理解都保留关联主题、适用边界和形成依据。

地图主题与深层理解双向联动：聚焦主题时，相关深层理解随之显现；聚焦深层理解时，来源主题在地图中被定位。打开详情后，仍使用统一抽屉查看完整内容与证据。

### 记录轨迹

“记录轨迹”进入顶部次级操作，按日期回看最近一段时间的内容去向。它承担历史找回，不与深层理解争夺首页视觉权重。

### 抽屉

主题、深层理解、日期和原始记录共享一套抽屉。用户沿同一条路径逐层深入，并能用 Escape 关闭后回到原触发点。

## 7. 视觉与交互原则

当前视觉方向来自 `Time Echo / 时间回声`，同时采用 `Quiet Evidence / 安静证据` 的信息克制。

- 暖奶油纸面和轻微时间纹理；
- 墨色正文与单一蓝色强调；
- 发丝线代替卡片墙；
- 日期与来源使用等宽字体；
- 群山是页面的主要视觉签名；
- 常驻界面只显示主题、时间、事实数字和操作；
- 动效只服务选择、展开、平移、缩放和时间变化；
- 支持键盘、焦点恢复与 `prefers-reduced-motion`。
- 每个图形对象都提供等价文字路径和键盘入口，用户无需依赖空间位置理解内容。

## 8. 本地与信任边界

- 正式产品的原始记录保存在用户本地目录；
- v0.10.0 Preview 页面不联网；
- v0.10.0 Preview 不访问真实数据目录；
- 地图中的当前演示内容来自固定的 20 天窗口、261 条记录汇总和 6 条代表记录；
- 演示主题和代表记录使用明确的静态对象合同，供前端阅读路径与交互评审使用；
- 视觉位置不产生新的事实结论；
- 用户可以沿形成链查看来源、边界与适用范围。
