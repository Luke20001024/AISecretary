# Product Manager 20-day rich synthetic scenario

这组文件是 Memento Context Agent 的可回收合成验证数据，不代表用户事实。日期为
2026-07-14 至 2026-08-02，共 20 个连续自然日、每天 10 条、总计 200 条；复制到
Vault 时，必须先确认目标文件不存在，不能覆盖真实记录。每个文件都带有
`MEMENTO_SYNTHETIC_CONTEXT_TEST_V2_RICH` 标记和合成数据提示。

每天固定混合 8 条高频产品工作噪音与 2 条重点信号：

- 当日主题、指标口径、用户研究、研发同步、设计细节、竞品观察、一次性事务和风险记录；
- 稳定工作偏好、项目决定、硬约束、阶段性判断、前后冲突或安全测试信号。

这些噪音不是无意义占位文本：它们用于验证模型能否避免把会议改期、视觉探索、竞品观察、
实现状态和单次研究样本错误提升为长期个人特征。

主验证窗口为 2026-07-20 至 2026-08-02，共 14 天。该窗口包含：

- 跨 4 天重复的稳定工作偏好；
- 跨 2 天重复的本地优先项目决定；
- 跨 2 天重复的用户确认硬约束；
- 一条有明确试行周期的阶段性项目决定；
- 一次性视觉想法与尚未形成决定的兴趣记录。

2026-07-14 至 2026-07-19 刻意放入前后变化的优先级决定、一次性视觉想法和
提示注入/敏感推断测试文本，用来验证这些内容不应被静默当作稳定长期 Context。

当前 P1.0 每次最多生成一条候选，所以 `ground-truth.json` 中的多个合格主题不是要求
单次全部产出；真实验证只接受其中一条，并且必须通过逐字证据与来源哈希校验。

重新生成：

```bash
python3 context-agent/eval/scenarios/product-manager-20d/generate_rich_fixture.py
```

生成器是确定性的；重复运行应得到相同的 20 个 Markdown 文件。
