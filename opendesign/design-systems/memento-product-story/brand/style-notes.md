# Style Notes

## 产品气质

Memento 的视觉来自 Time Echo 的时间层次和 Quiet Evidence 的信息克制。纸面提供时间感，等高线提供长期积累的形状，蓝色标记提供证据与变化的方向。

这套语言允许从现有产品继续生长。界面中的规则网格只保留必要骨架，讲述页可以采用断裂墨线、轻微错位、复印叠印和不对称留白。蓝色保持稀少，只落在证据、路径和变化发生的位置。

避免把所有信息装进尺寸相同的盒子。真实截图应当像被留下的证据切片进入纸面，边缘可以裁切、遮罩或叠印，同时保留来源与可读内容。

## 页面骨架

建议使用四个连续画面：

1. 封面：一句话与横版地平线海报
2. 散落的意图：真实窗口交叠，蓝色线索在窗口之间中断
3. 生长的地形：记录流进入地图，轮廓随着证据依次长出
4. 可调用的个人记忆：形成链、她理解的我、本地数据与外接 AI 合并为“让每个 AI 都从同一个你开始”的终幕

封面保持宽阔，图像质感可以铺满首屏，标题借用图像中的自然留白。进入正文后迅速收紧。正文每一幕控制在一个桌面视口左右，总页长维持在四屏附近。

## 真实窗口处理

- 使用系统或应用的真实窗口边框
- 每个窗口只保留一个能代表意图的内容区域
- 个人姓名、头像、公司和敏感信息统一脱敏
- 允许 12–28px 的交叠、0–2° 的旋转和轻微高低差
- 来源标签放在窗口下缘，格式示例 `CHAT · 10:42 · 原始记录`
- 重要句子用一条细蓝线或小圆点标记，不使用荧光色大面积涂抹
- 首屏同时出现的窗口建议控制在 3–5 个

当真实截图尚未准备好时，可以先用 HTML 重构窗口场景。场景需标注 `Scene reconstruction / 场景重构`，只保留能够识别来源类型的结构，不复制完整第三方产品，也不承担产品能力证明。真实截图到位后应逐层替换，版式、标注和动效保持不变。

## 地形生长

地形从证据点附近开始出现。第一层轮廓很淡，随后在同一主题的记录积累时向外扩展；主题名在轮廓稳定后出现；关系线只在确认关系后连接。动画重点是“新的证据改变了现有地形”，避免单纯播放装饰性波纹。

## 组件对应

| 真实产品原语 | 讲述页用法 |
| --- | --- |
| 记录行的时间轴和节点 | 窗口下方的记录流 |
| 地图的证据点 | 标记真实窗口中的关键意图 |
| 等高线 | 表达主题随证据积累生长 |
| 形成链抽屉 | 解释一份理解如何形成与被修订 |
| 等宽来源信息 | 证明截图和结论的出处 |
| 蓝色变化状态 | 表示新证据、近期变化与可调用入口 |

## 响应式与无障碍

- 窄屏将窗口从交叠改为纵向证据带
- 关键文字不能依赖图片中的小字，需要在旁侧补充短句
- 颜色之外再用线型、标签和图形区分状态
- 焦点态使用 `--memento-blue-deep`
- 减少动态模式下直接显示最终关系，不做顺序动画
